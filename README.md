# Система учёта коммерческих предложений

Консольное приложение для создания, обработки и хранения коммерческих
предложений.

## Целевая аудитория

Менеджеры по продажам и сотрудники небольших компаний, которые готовят
коммерческие предложения для клиентов.

## Предметная область

Коммерческое предложение содержит номер, клиента, исходную сумму, скидку,
дату создания, срок действия и статус. Данные нескольких предложений сохраняются
между запусками программы в формате JSON.

## Возможности

- просмотр всех коммерческих предложений;
- поиск по номеру предложения или названию клиента;
- проверка уникальности номера и добавление предложения;
- согласование и отмена предложения;
- расчёт итоговой суммы с учётом скидки;
- расчёт даты окончания срока действия;
- фильтрация предложений по статусу с помощью генератора;
- сортировка предложений по итоговой сумме;
- расчёт сводной статистики;
- сохранение и загрузка данных в формате JSON;
- обработка ошибок ввода и файловых операций.

## Структура проекта

- `main.py` — точка запуска и меню приложения;
- `proposals.py` — функции обработки коммерческих предложений;
- `storage.py` — загрузка и сохранение JSON-данных;
- `utils.py` — функции безопасного пользовательского ввода;
- `data/proposals.json` — данные коммерческих предложений;
- `tests/test_proposals.py` — автоматические тесты;
- `requirements.txt` — инструменты тестирования и проверки кода.

## Формат данных

Предложения хранятся в `data/proposals.json` в виде списка словарей. Каждая
запись содержит поля `id`, `number`, `client`, `amount`, `discount_percent`,
`created_date`, `validity_days` и `status`.

## Требования

- Python 3.x;
- pytest;
- flake8.

## Установка зависимостей

```bash
python3 -m pip install -r requirements.txt
```

## Запуск программы

```bash
python3 main.py
```

## Запуск тестов

```bash
python3 -m pytest
```

```bash

```
